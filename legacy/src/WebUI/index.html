بوابة الطلاب (Student Web App)

الداش بورد (Admin Dashboard)

لوحة التحكم المركزية لإدارة الكلية: استعراض إحصائيات المشروعات، ضبط كوتة وتوزيع المشرفين على الفرق، إدارة المستخدمين، واستخراج تقارير الأداء الشاملة.

فتح لوحة التحكم (الداش بورد) ←
📌 الموديولات المنجزة وفق تقسيم الـ 8 أفراد: 35/35 اختبار نجاح (100%)
01. إدارة المستخدمين

تسجيل، دخول، تشفير SHA256، وصلاحيات RBAC متقدمة.

02. الأفكار والذكاء الاصطناعي

تقديم الأفكار وكشف تشابه النصوص Cosine Similarity لمنع السرقة والتكرار.

03. الفرق وتوزيع المشرفين

تكوين الفرق، الدعوات، وضبط كوتة الإشراف الأكاديمي (حد أقصى 3 فرق).

04. لوحة المهام والمتابعة

لوحة Kanban ثلاثية، حساب نسبة الإنجاز والإنذارات التلقائية للمواعيد.
