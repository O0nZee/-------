# الملفات القديمة المحفوظة

هذا المجلد يحفظ المصادر المكررة السابقة في src، والملفات التنفيذية القديمة، وصفحة التحويل القديمة. لا تدخل هذه الملفات في بناء التطبيق الحالي.

شغّل النسخة الحالية باستخدام Start.cmd من المجلد الرئيسي. الكود الذي يُبنى موجود في Backend وProgram.cs، والواجهات في Frontend وUI_UX، والاختبارات الحالية عبر scripts/Test.ps1.

الملفات التنفيذية داخل bin تم تجميعها قبل تحديث المشروع، لذلك قد تعرض وظائف أو نتائج مختلفة عن النسخة الحالية.
